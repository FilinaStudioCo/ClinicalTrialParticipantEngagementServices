# Images folder

This folder holds the site's photographic assets. Upload your files here with these exact names so the HTML references resolve correctly:

- `portrait.jpg` — professional portrait used on `about.html`
- `hero-photo.jpg` (or `.png`) — editorial hero image used on `index.html`. If you upload a `.png` instead of `.jpg`, update the `src` attribute in `index.html`'s hero section to match.

Recommended: warm-toned, editorial images, landscape or portrait orientation, at least 1200px on the longest side, optimized for web (under ~500KB each) for fast page loads.
